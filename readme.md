# 💖 Interactive Proposal Web Experience

A creative **multi-page interactive web project** built using **HTML, CSS, and JavaScript**, designed to deliver a playful, animated, and emotionally engaging proposal-style experience.

This project demonstrates frontend creativity, animation logic, event-driven navigation, and clean UI storytelling — all without any external frameworks.

---

## 📌 Project Overview

**Interactive Proposal Web Experience** is a fun and expressive web-based flow that guides users through a sequence of romantic and playful interactions such as:

- Animated proposal prompts
- Click-based decisions
- Surprise reveals
- Date selection
- A final “date contract” celebration 🎆

Each page is thoughtfully designed with **animations, transitions, and user interaction**, making the experience feel personal and immersive.

This project highlights how simple web technologies can be used to build **emotion-driven UI experiences**.

---

## 🎯 Key Features

- 💌 Multi-page interactive flow
- 💖 Floating heart animations using pure CSS & JS
- 🎁 Surprise reveal pages with smooth transitions
- 🏃 Playful “No button” movement logic
- 🎆 Fireworks animation using HTML Canvas
- 📱 Fully Responsive design
